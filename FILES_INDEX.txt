🚀 QUICK START (DO THIS NOW)

1. READ: GETTING_STARTED.md (5 min read)

2. CREATE FIREBASE PROJECT:
   - Go to: https://console.firebase.google.com/
   - Create new project: "freshmart-grocery"

3. ENABLE SERVICES:
   - Authentication → Email/Password + Google
   - Firestore Database → Start in test mode

4. UPDATE CONFIG:
   - Open: js/firebase-config.js
   - Replace placeholders with your credentials

5. UPDATE SECURITY RULES:
   - Copy from FIREBASE_SETUP.md
   - Paste in Firestore → Rules

6. START SERVER:
   npm start
   (or: python -m http.server 8000)

7. TEST:
   http://localhost:8000/auth.html

📊 DATABASE COLLECTIONS (Ready to use)

/users/{uid}
  - email, name, phone, address
  - cart: array of cart items
  - orders: array of order IDs
  - favorites: array of product IDs
  - createdAt: timestamp

/orders/{orderId}
  - items: array of ordered items
  - total: order total
  - status: confirmed/processing/shipped/delivered
  - trackingUpdates: array of status updates

/products/{productId}
